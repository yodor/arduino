LDR attenuator firmware -- 2026-10-30j  (driver v1b, 2nd-edition LDR boards)

Protocol 20 (see ldr-attenuator-protocol.md, "Revision 20"):
* CAL VERIFY (protocol and console) runs the verify through CAL's own path: a status line,
  STATUS=BUSY with CAL=OK while it runs, PROGRESS KIND=VERIFY (CHECK/STEPS/WALK/CREEP).
* VERIFY RESULT: the newest run in one line (residuals, movement, middle steps, rms, L-R,
  ADOPTED, VERDICT=OK|RESYNC|CHECK). Console: VERIFY [HISTORY] lists the stored runs.
* ENV: RESYNC=1 WHY=VERIFY after a run with verdict RESYNC (held while warming up).
* The run's walk is adopted automatically when safe (not on CHECK, not if AUTO would change
  Rtotal, not if a manual Rtotal is not reached). The manual VERIFY ADOPT is gone.
Included from 30i: re-solves no longer write learning entries (FORGET COMP once, then resync).
Tests: python3 test/run_tests.py (22 + source check).
