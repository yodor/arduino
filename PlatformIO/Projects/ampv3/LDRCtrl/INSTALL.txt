Cold start fix: the thermal compensation was capped at +-15 counts -- only ~2.8 C at the learned
~5.4 counts/C. After a complete power-off, the block starts 5-8 C below a warm calibration and
needs 27-43 counts, so the middle steps played quiet until a resync. The cap is now +-45 counts
(~8 C). TEMP / DIAG say "AT THE SAFETY LIMIT" if it is ever reached. A broken NTC still gives
no offset at all. Everything from 2026-10-26a (SET SRC / SET LOAD, MODEL, COMP) included.

firmware.uf2 is a real build: hold BOOTSEL, plug in, copy it to RPI-RP2. Or build from src/.
