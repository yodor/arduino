LDR daughter board firmware -- 2026-10-17a (protocol 8: ENV + PROGRESS for the master display)  (driver v1b)

Protocol revision 8 (STATUS unchanged apart from PROTO=8):
  ENV       temperatures, rail, thermal compensation state, last L/R match -- instant
  PROGRESS  what a running calibration is doing: KIND, PHASE, SIDE, STEP i/n, PCT, ETA
Both are answered at any time, including DURING a calibration and the boot hold.
The cell sensors are read in the background every 30 s (no 750 ms block in a reply).
See daughter-board-uart-protocol-v2.md, section "Revision 8", for the master side.

1. DELETE your project's src/ folder, copy this package's src/ next to platformio.ini,
   and replace platformio.ini with the one in this package.
2. pio run -t clean ; pio run ; flash .pio/build/picow/firmware.uf2 (BOOTSEL + copy).
3. Boot: no format change; calibration, learning log and references are kept.
