Fix: the shunt sweep could read a cell still recovering from the series sweep's bright hold
(readable at the darkest duties, then unreadable) and those "lag island" readings hid the
real dark edge -> no dark-edge refinement -> the shunt curve stopped at ~261k and capped RMAX.
Now each sweep starts from a cell held dark for 4 s, lag islands are dropped, and the dark
edge is found where the continuous readable run begins.

2. pio run -t clean ; pio run ; flash .pio/build/picow/firmware.uf2 (BOOTSEL + copy).
3. Boot: no format change, the stored calibration is kept. To re-measure the reach:
     DEBUG, FORGET, CAL      (a plain CAL would only resync -- the cells match)
