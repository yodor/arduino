LDR daughter board firmware -- 2026-10-15l (3.3 V rail compensation via the TL431)  (driver v1b)

3.3 V rail compensation (TL431). The LED drive is duty x rail; every duty now goes to the
PWM as duty x (reference rail / rail now), so the drive stays what the calibration measured.
* The reference is the rail the curves were measured at: stored by each full
  characterization, or -- the first time, as now -- by the next calibration of any kind.
* Re-measured every 3 s while idle; re-applied when it moves by more than 0.02 %.
  Never during a calibration. Corrections beyond 3 % are treated as a bad reading.
* TEMP and DIAG show it:  rail compensation: reference 3.3320 V, now 3.3340 V -> drive x0.99940
Also contains 2026-10-15k: the thermal learning log (LEARN).

1. DELETE your project's src/ folder, copy this package's src/ next to platformio.ini,
   and replace platformio.ini with the one in this package.
2. pio run -t clean ; pio run ; flash .pio/build/picow/firmware.uf2 (BOOTSEL + copy).
3. Boot: no format change. Then DEBUG, CAL -- this first resync stores the reference rail
   AND the starting environment for the learning log. From then on: CAL at different
   temperatures, and LEARN once there are 3+ resyncs.
